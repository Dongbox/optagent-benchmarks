# CVRPLIB

## 数据来源说明

CVRPLIB 是容量约束车辆路由问题的公开基准数据集，用于评估车辆路由优化算法。

数据集来源：

- CVRPLIB 主页：https://vrp.atd-lab.inf.puc-rio.br/index.php/en/
- CVRP 实例页：https://galgos.inf.puc-rio.br/cvrplib/index.php/en/instances
- 本地完整数据：benchmarks/cases/cvrplib/cvrp/raw/cvrp_instances/
- 当前筛选数据：benchmarks/cases/cvrplib/cvrp/raw/

## 问题说明

在固定车辆数和车辆容量下，从 depot 出发并回到 depot，每个客户恰好访问一次，每条路线的客户需求不超过车辆容量，目标是最小化所有路线的总距离。

## 数据筛选依据

- 数规模定义：nodes=客户数+1，customers=nodes-1，并保留 vehicles、capacity 和 directed_arcs 作为辅助规模特征。
tier 分类范围：

| tier | case 数量 | nodes 范围 |
|---|---:|---:|
| smoke | 17 | 16–80 |
| calibration | 31 | 81–200 |
| full | 15 | 201–500 |
| pressure | 16 | 501–1200 |

- 筛选策略：先按规模分层，再综合比较车辆数、容量、需求分布、距离分布、近邻结构、仓库距离和空间密度，去除结构高度重复的算例，同时保留不同来源系列的代表。

## 建模说明

使用二元弧变量表示路线是否选择，使用单商品流变量与流平衡约束消除子环，并最小化选中弧的总距离。

- 适用的求解方式：solve() 和 solve_milp() 适用；solve_cpsat() 当前不作为本数据集的标准求解路径，因为当前建模和测试配置未提供 CPSAT lowering。

## 特殊备注

本数据集采用固定车队口径。XML、Golden、Tai 和 Li 的部分原始实例未显式给出车辆数，已根据参考解的路线数人为固定 vehicles，因此这里是固定车辆数下的单目标总距离问题。不固定车辆数的特殊口径放在 CVRP2LIB。
