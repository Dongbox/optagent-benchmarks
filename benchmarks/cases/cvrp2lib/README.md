# CVRP2LIB

## 数据来源说明

CVRP2LIB 是为不固定车辆数的容量约束车辆路由问题保留的特殊数据集，当前主要包含 XML100 生成族。

数据集来源：

- CVRPLIB 主页：https://vrp.atd-lab.inf.puc-rio.br/index.php/en/
- XML100 数据说明：https://galgos.inf.puc-rio.br/cvrplib/en/xml100
- 本地 XML 数据：benchmarks/cases/cvrp2lib/cvrp_xml/raw/XML/
- 当前筛选数据：benchmarks/cases/cvrp2lib/cvrp_xml/raw/

## 问题说明

在给定 depot、客户需求、车辆容量和节点距离的前提下，为每个客户分配路线，每条路线从 depot 出发并回到 depot，每个客户恰好访问一次，路线需满足容量约束。当前输入不固定车辆数，参考解同时记录路线数和总距离。

## 数据筛选依据

- 数规模定义：nodes=客户数+1，customers=nodes-1，输入 vehicles=null，并记录 capacity 和 directed_arcs。
- tier 范围：当前所有 XML 算例均为 calibration，规模为 nodes=101、customers=100。
- 筛选策略：在完整 XML100 生成族中比较容量、需求结构、距离结构、仓库距离和名称编码特征，优先保留各类生成机制和结构代表，去掉高度近似算例，最终保留 55 个。

## 建模说明

待建模。

## 特殊备注

当前选中实例的 size.vehicles 保持 null，reference.vehicles 与 reference.route_count 记录官方解的路线数，reference.objective 记录参考解总距离。它与 CVRPLIB 的固定车队口径分开维护。
